# SnapMark 사용 설명서

SnapMark는 Windows 화면을 캡처하고, **나중에도 편집할 수 있는** 주석을 달 수 있게 해 주는 앱입니다. 사각형, 화살표, 텍스트, 가리기 등은 이미지에 그려 넣은 픽셀이 아니라 각각 독립된 개체입니다. 원본 이미지는 절대 수정되지 않습니다.

## 설치

설치 프로그램 `SnapMark_x.y.z_x64-setup.exe`를 실행하세요. 현재 사용자 계정에만 설치되며 관리자 권한은 필요 없습니다. 설치 후 SnapMark는 **알림 영역**(시계 근처의 아이콘 영역, 시스템 트레이라고도 함)에서 실행됩니다. 아이콘이 보이지 않으면 ^ 화살표를 눌러 숨겨진 아이콘을 표시하세요.

알림 영역 아이콘을 마우스 오른쪽 버튼으로 클릭하면 메뉴가 열립니다: **캡처**, **기록**, **프로젝트 열기…**, **설정**, **종료**.

## 화면 캡처하기

1. **Print Screen**을 누릅니다 (알림 영역 아이콘을 클릭하거나 **캡처**를 선택해도 됩니다). 화면이 잠시 멈추며, 모니터가 여러 대면 모두 캡처됩니다.
2. **드래그**하여 영역을 선택합니다. 주석을 추가한 뒤에도 언제든 영역을 바꿀 수 있습니다. **테두리**를 드래그하면 이동, 모서리나 변의 **핸들**을 드래그하면 크기 조절, 바깥의 어두운 부분을 드래그하면 다시 선택됩니다. 방향키로 영역을 옮기고, **Ctrl + 방향키**로 크기를 바꾸며, **Shift**를 누르면 10픽셀씩 움직입니다.
3. 도구 모음으로 주석을 추가합니다.
4. **Enter**를 누르면 클립보드에 복사되고, **Ctrl+S**를 누르면 저장됩니다. **Esc**는 취소입니다.

첫 번째 Esc는 개체 선택을 해제하고, 다음 Esc는 SnapMark를 닫습니다.

## 주석 도구

| 도구 | 키 | 참고 |
|---|---|---|
| 선택 및 편집 | `V` | 개체를 클릭해 선택합니다. **Shift+클릭**으로 선택에 추가/제외합니다. 드래그하여 이동하고, 핸들을 당겨 크기를 조절합니다. |
| 사각형 | `R` | **Shift** = 정사각형. 채우기 가능. |
| 타원 | `E` | **Shift** = 원. |
| 선 | `L` | **Shift** = 45° 단위로 고정. 스타일: 실선, 이중선, 점선. |
| 화살표 | `A` | **Shift** = 45°. 한쪽 또는 양쪽 끝에 화살촉. |
| 자유 펜 | `P` | 자유롭게 그리기. |
| 형광펜 | `H` | 반투명 마커. |
| 가리기 | `S` | 모자이크, 흐림 또는 **검은 블록**(가장 안전). 사각형 또는 브러시 모양. |
| 단계 번호 | `N` | 클릭할 때마다 1, 2, 3… 순서대로 배치. |
| 텍스트 | `T` | 배경 선택 가능. **Ctrl+Enter** 또는 **Esc**로 완료. |

색상, 선 굵기, 글꼴 크기, 굵게는 도구 모음에서 설정하며, 선택한 개체에 적용됩니다.

## 키보드 단축키

| 키 | 동작 |
|---|---|
| `Enter` / `Ctrl+C` | 결과를 클립보드에 복사 |
| `Ctrl+S` | 저장 폴더에 PNG 저장 |
| `Ctrl+Shift+S` | 다른 이름으로 저장… |
| `Ctrl+Alt+S` | `.snapmark` 프로젝트 저장 |
| `Ctrl+Z` / `Ctrl+Y` (또는 `Ctrl+Shift+Z`) | 실행 취소 / 다시 실행 |
| `Ctrl+D` | 선택한 개체 복제 |
| `Ctrl+A` | 모든 개체 선택 |
| `Ctrl+]` / `Ctrl+[` | 맨 앞으로 / 맨 뒤로 |
| `Delete` / `Backspace` | 선택한 개체 삭제 |
| 방향키 (`Shift` = 10 px) | 선택한 개체 이동. 선택이 없으면 영역 이동 (`Ctrl` 병용: 영역 크기 조절) |
| `Esc` | 선택 해제, 한 번 더 누르면 닫기 |

## 복사와 저장

결과는 항상 **선택한 영역만**, 화면의 **원래 해상도**로, 보이는 그대로 만들어집니다.

- **복사** (Enter): 클립보드에 들어가 바로 붙여넣을 수 있습니다.
- **저장** (Ctrl+S): 저장 폴더에 `snapmark_20261125_143005.png`(날짜_시간) 이름으로 바로 저장합니다. 같은 이름의 파일은 덮어쓰지 않습니다(`_2`, `_3`… 이 붙습니다). 기본 폴더: `사진\SnapMark`.
- **다른 이름으로 저장** (Ctrl+Shift+S): 이름과 폴더를 직접 고릅니다.

복사나 저장에 성공하면 SnapMark가 자동으로 닫힙니다.

## 프로젝트와 기록

**`.snapmark` 프로젝트**는 원본 이미지와 모든 주석을 개체로 저장하므로, 나중에 다시 열어 편집할 수 있습니다. **Ctrl+Alt+S**로 저장하고, 파일을 더블클릭하거나 알림 영역 → **프로젝트 열기…**로 엽니다.

> **가리기에 주의하세요.** 프로젝트 파일에는 *원본* 이미지가 들어 있으므로, 가려 둔 부분도 그 파일을 여는 누구나 볼 수 있습니다. 공유할 때는 가려진 결과만 담기는 **복사** 또는 **PNG 저장**을 사용하세요. 가리기가 포함된 프로젝트를 저장하기 전에 SnapMark가 경고합니다.

**기록**: 복사/저장할 때마다 편집 가능한 프로젝트로 자동 기록됩니다(기본 최근 50개, 이 컴퓨터에서만). 알림 영역 → **기록**에서 열고, 항목을 클릭하면 다시 편집할 수 있습니다.

## 설정

알림 영역 → **설정**.

| 항목 | 설명 |
|---|---|
| 캡처 단축키 | 기본값은 `Print Screen`. **변경…**을 누르고 새 조합을 누르세요 (입력에 방해되지 않도록 Ctrl/Alt/Win을 함께 사용). |
| 저장 폴더 | Ctrl+S의 저장 위치. |
| 언어 | Bahasa Indonesia, English, Español, Deutsch, 日本語, 简体中文, Français, Italiano, Português (Brasil), 한국어, Русский, العربية, Nederlands, 또는 Windows와 동일. |
| 기록 | 보관할 항목 수 (0 = 끔, 최대 500). |
| Windows와 함께 시작 | 로그인하면 바로 SnapMark를 쓸 수 있습니다. |
| 안내 색상 | 영역을 고를 때 표시되는 안내 문구의 색상. |
| 테마 | Windows와 동일, 밝게, 어둡게, Liquid Glass. |
| 업데이트 | 6시간마다 자동 확인·설치, 또는 **지금 확인**. |

업데이트는 공식 릴리스에서 내려받아 설치 창 없이 설치되며 SnapMark가 자동으로 다시 열립니다. 설정과 기록은 유지됩니다. 편집 중이면 끝날 때까지 설치를 기다립니다.

## 개인정보 보호

- 스크린샷과 프로젝트는 **컴퓨터 밖으로 나가지 않습니다**.
- 원격 측정(텔레메트리)이 없습니다. 네트워크 접속은 업데이트 확인뿐입니다.

## 문제 해결

**Print Screen을 눌러도 반응이 없음 / 단축키가 비활성.** Windows 11은 이 키를 자체 화면 캡처 도구에 할당할 수 있습니다. SnapMark 설정에서 **Windows 키보드 설정 열기**를 누르고, Print Screen 키로 그 도구를 여는 옵션을 끄세요(옵션의 이름과 위치는 Windows 버전에 따라 다릅니다). 또는 다른 단축키를 고르세요.

**알림 영역 아이콘이 보이지 않음.** 작업 표시줄의 ^ 화살표를 누르고, SnapMark 아이콘을 밖으로 끌어 항상 보이게 하세요.

**데이터 위치.** 설정: `%APPDATA%\app.snapmark.desktop\settings.json`. 기록: `%LOCALAPPDATA%\app.snapmark.desktop\history`.
