# Руководство пользователя SnapMark

SnapMark делает снимки экрана Windows и позволяет добавлять аннотации, которые **остаются редактируемыми**: рамки, стрелки, текст, скрытие данных и другое — это отдельные объекты, а не пиксели, нарисованные на картинке. Исходное изображение никогда не изменяется.

## Установка

Запустите установщик `SnapMark_x.y.z_x64-setup.exe`. Он устанавливается только для вашей учётной записи (права администратора не нужны). После этого SnapMark работает в **области уведомлений** (значки возле часов). Если значка не видно, нажмите стрелку ^, чтобы показать скрытые значки.

Щёлкните значок правой кнопкой, чтобы открыть меню: **Снимок**, **История**, **Открыть проект…**, **Настройки**, **Выход**.

## Снимок экрана

1. Нажмите **Print Screen** (или щёлкните значок в области уведомлений, или выберите **Снимок**). Экран на мгновение замирает; если мониторов несколько, снимаются все.
2. **Перетащите** мышь, чтобы выбрать область. Её можно менять в любой момент, даже после добавления аннотаций: перетащите **контур**, чтобы переместить, **маркер** на углу или стороне, чтобы изменить размер, либо перетащите по тёмной области снаружи, чтобы выбрать заново. Стрелки на клавиатуре сдвигают область; **Ctrl + стрелка** меняет её размер; **Shift** делает шаг в 10 пикселей.
3. Добавляйте аннотации с помощью панели инструментов.
4. **Enter** копирует в буфер обмена, **Ctrl+S** сохраняет. **Esc** отменяет.

Первое нажатие Esc снимает выделение объектов, следующее закрывает SnapMark.

## Инструменты аннотаций

| Инструмент | Клавиша | Примечания |
|---|---|---|
| Выбор и правка | `V` | Щёлкните объект, чтобы выбрать его; **Shift+щелчок** добавляет в выделение или убирает из него. Перетаскивайте для перемещения, тяните маркер для изменения размера. |
| Прямоугольник | `R` | **Shift** = квадрат. Можно залить. |
| Эллипс | `E` | **Shift** = круг. |
| Линия | `L` | **Shift** = углы кратные 45°. Стили: сплошная, двойная, пунктир. |
| Стрелка | `A` | **Shift** = 45°. Наконечник на одном или обоих концах. |
| Свободное перо | `P` | Рисование от руки. |
| Маркер | `H` | Полупрозрачный маркер. |
| Скрыть | `S` | Мозаика, размытие или **чёрный блок** (надёжнее всего). Форма — прямоугольник или кисть. |
| Номер шага | `N` | Каждый щелчок ставит 1, 2, 3… по порядку. |
| Текст | `T` | Фон на выбор. **Ctrl+Enter** или **Esc** завершает ввод. |

Цвет, толщина линии, размер шрифта и жирность задаются на панели инструментов; изменения применяются к выбранным объектам.

## Сочетания клавиш

| Клавиша | Действие |
|---|---|
| `Enter` / `Ctrl+C` | Копировать результат в буфер обмена |
| `Ctrl+S` | Сохранить PNG в папку сохранения |
| `Ctrl+Shift+S` | Сохранить как… |
| `Ctrl+Alt+S` | Сохранить проект `.snapmark` |
| `Ctrl+Z` / `Ctrl+Y` (или `Ctrl+Shift+Z`) | Отменить / повторить |
| `Ctrl+D` | Дублировать выбранные объекты |
| `Ctrl+A` | Выбрать все объекты |
| `Ctrl+]` / `Ctrl+[` | На передний план / на задний план |
| `Delete` / `Backspace` | Удалить выбранные объекты |
| Стрелки (`Shift` = 10 px) | Сдвинуть выбранные объекты; если ничего не выбрано — сдвинуть область (с `Ctrl`: изменить её размер) |
| `Esc` | Снять выделение, затем закрыть |

## Копирование и сохранение

Результат — всегда **только выбранная область** в **исходном разрешении** экрана, в точности как вы её видите.

- **Копировать** (Enter): попадает в буфер обмена, можно сразу вставлять.
- **Сохранить** (Ctrl+S): сразу в папку сохранения под именем `snapmark_20261125_143005.png` (дата_время). Существующие файлы не перезаписываются (добавляется суффикс `_2`, `_3`, …). Папка по умолчанию: `Изображения\SnapMark`.
- **Сохранить как** (Ctrl+Shift+S): имя и папку выбираете сами.

После успешного копирования или сохранения SnapMark закрывается автоматически.

## Проекты и история

**Проект `.snapmark`** хранит исходное изображение и каждую аннотацию как объект, поэтому его можно открыть и править позже. Сохраняйте через **Ctrl+Alt+S**; открывайте двойным щелчком по файлу или через область уведомлений → **Открыть проект…**.

> **Осторожно со скрытием данных.** Файл проекта хранит *исходное* изображение, поэтому всё, что вы скрыли, увидит любой, кто откроет этот файл. Чтобы поделиться, используйте **Копировать** или **Сохранить PNG** — в них только скрытый результат. Перед сохранением проекта со скрытыми областями SnapMark предупредит вас.

**История**: каждое копирование/сохранение автоматически записывается как редактируемый проект (по умолчанию последние 50, только на этом компьютере). Откройте её через область уведомлений → **История** и щёлкните элемент, чтобы править снова.

## Настройки

Область уведомлений → **Настройки**.

| Параметр | Описание |
|---|---|
| Горячая клавиша снимка | По умолчанию `Print Screen`. Нажмите **Изменить…** и нажмите новое сочетание (с Ctrl/Alt/Win, чтобы не мешать набору текста). |
| Папка сохранения | Куда сохраняет Ctrl+S. |
| Язык | Bahasa Indonesia, English, Español, Deutsch, 日本語, 简体中文, Français, Italiano, Português (Brasil), 한국어, Русский, العربية, Nederlands или как в Windows. |
| История | Сколько элементов хранить (0 = выкл., максимум 500). |
| Запускать вместе с Windows | SnapMark готов сразу после входа в систему. |
| Цвет подсказки | Цвет текста с инструкцией при выборе области. |
| Тема | Как в Windows, Светлая, Тёмная или Liquid Glass. |
| Обновления | Автоматическая проверка и установка каждые 6 часов или кнопка **Проверить сейчас**. |

Обновления загружаются из официального релиза, устанавливаются без окна установщика, а SnapMark сам открывается снова; настройки и история сохраняются. Если вы редактируете, установка ждёт, пока вы закончите.

## Конфиденциальность

- Снимки и проекты **никогда не покидают ваш компьютер**.
- Телеметрии нет. Единственное обращение к сети — проверка обновлений.

## Устранение неполадок

**Print Screen ничего не делает / горячая клавиша не работает.** Windows 11 может назначить эту клавишу собственному средству создания снимков экрана. В настройках SnapMark нажмите **Открыть параметры клавиатуры Windows** и отключите параметр, при котором клавиша Print Screen открывает это средство (название и расположение параметра зависят от версии Windows). Или выберите другую горячую клавишу.

**Нет значка в области уведомлений.** Нажмите стрелку ^ на панели задач и вытащите значок SnapMark наружу, чтобы он был виден всегда.

**Где хранятся данные.** Настройки: `%APPDATA%\app.snapmark.desktop\settings.json`. История: `%LOCALAPPDATA%\app.snapmark.desktop\history`.
