# SnapMark 使用指南

SnapMark 可以截取 Windows 屏幕，并添加**之后仍可编辑**的标注：矩形、箭头、文字、遮盖等都是独立的对象，而不是画在图片上的像素。原始图像永远不会被修改。

## 安装

运行安装程序 `SnapMark_x.y.z_x64-setup.exe`。它只为当前用户安装，无需管理员权限。安装完成后，SnapMark 在**通知区域**（时钟附近的图标区域，也称系统托盘）中运行。如果看不到图标，请点击 ^ 箭头显示隐藏的图标。

右键点击通知区域图标打开菜单：**截图**、**历史记录**、**打开项目…**、**设置**、**退出**。

## 截取屏幕

1. 按 **Print Screen**（或点击通知区域图标，或选择**截图**）。屏幕会短暂定格；如果有多个显示器，会全部截取。
2. **拖动**以选择区域。区域可随时调整，添加标注之后也可以：拖动**边框**来移动，拖动角或边上的**控制点**来调整大小，在外侧暗处拖动可重新选择。方向键微调区域位置；**Ctrl + 方向键**调整大小；按住 **Shift** 每次移动 10 像素。
3. 使用工具栏添加标注。
4. 按 **Enter** 复制到剪贴板，或按 **Ctrl+S** 保存。**Esc** 取消。

第一次按 Esc 会取消对象选择，再按一次则关闭 SnapMark。

## 标注工具

| 工具 | 按键 | 说明 |
|---|---|---|
| 选择并编辑 | `V` | 点击对象即可选中；**Shift+点击**可增减选择。拖动移动，拖动控制点调整大小。 |
| 矩形 | `R` | **Shift** = 正方形。可填充。 |
| 椭圆 | `E` | **Shift** = 圆形。 |
| 直线 | `L` | **Shift** = 锁定 45° 角。样式：实线、双线、虚线。 |
| 箭头 | `A` | **Shift** = 45°。一端或两端带箭头。 |
| 自由画笔 | `P` | 自由绘制。 |
| 荧光笔 | `H` | 半透明标记。 |
| 遮盖 | `S` | 马赛克、模糊或**黑色方块**（最安全）。矩形或画笔形状。 |
| 步骤编号 | `N` | 每次点击依次放置 1、2、3…。 |
| 文字 | `T` | 可选背景。**Ctrl+Enter** 或 **Esc** 完成输入。 |

颜色、线条粗细、字号和加粗可在工具栏中设置，更改会应用到当前选中的对象。

## 键盘快捷键

| 按键 | 功能 |
|---|---|
| `Enter` / `Ctrl+C` | 将结果复制到剪贴板 |
| `Ctrl+S` | 将 PNG 保存到保存文件夹 |
| `Ctrl+Shift+S` | 另存为… |
| `Ctrl+Alt+S` | 保存 `.snapmark` 项目 |
| `Ctrl+Z` / `Ctrl+Y`（或 `Ctrl+Shift+Z`） | 撤销 / 重做 |
| `Ctrl+D` | 为选中的对象创建副本 |
| `Ctrl+A` | 选择所有对象 |
| `Ctrl+]` / `Ctrl+[` | 置于顶层 / 置于底层 |
| `Delete` / `Backspace` | 删除选中的对象 |
| 方向键（`Shift` = 10 px） | 移动选中的对象；未选中时移动区域（配合 `Ctrl`：调整区域大小） |
| `Esc` | 取消选择，再按则关闭 |

## 复制与保存

结果始终**只包含选中的区域**，以屏幕的**原始分辨率**输出，所见即所得。

- **复制**（Enter）：进入剪贴板，可直接粘贴。
- **保存**（Ctrl+S）：直接保存到保存文件夹，文件名如 `snapmark_20261125_143005.png`（日期_时间）。不会覆盖已有文件（会加上 `_2`、`_3`…后缀）。默认文件夹：`图片\SnapMark`。
- **另存为**（Ctrl+Shift+S）：自己选择文件名和文件夹。

复制或保存成功后，SnapMark 会自动关闭。

## 项目与历史记录

**`.snapmark` 项目**保存原始图像以及每个以对象形式存在的标注，因此以后可以重新打开并继续编辑。用 **Ctrl+Alt+S** 保存；双击文件，或通过通知区域 → **打开项目…** 打开。

> **请注意遮盖内容。** 项目文件保存的是*原始*图像，因此任何打开该文件的人都能看到被遮盖的内容。要分享时，请使用**复制**或**保存 PNG**，它们只包含已遮盖的结果。保存含有遮盖的项目之前，SnapMark 会给出提示。

**历史记录**：每次复制/保存都会自动记录为可再次编辑的项目（默认保留最近 50 条，仅保存在此电脑）。通过通知区域 → **历史记录**打开，点击某一项即可重新编辑。

## 设置

通知区域 → **设置**。

| 设置项 | 说明 |
|---|---|
| 截图热键 | 默认为 `Print Screen`。点击**更改…**，然后按下新的组合键（请配合 Ctrl/Alt/Win，以免影响打字）。 |
| 保存文件夹 | Ctrl+S 的保存位置。 |
| 语言 | Bahasa Indonesia、English、Español、Deutsch、日本語、简体中文、Français、Italiano、Português (Brasil)、한국어、Русский、العربية、Nederlands，或跟随 Windows。 |
| 历史记录 | 保留的条数（0 = 关闭，最多 500）。 |
| 随 Windows 启动 | 登录后 SnapMark 立即可用。 |
| 提示颜色 | 选择区域时说明文字的颜色。 |
| 主题 | 跟随 Windows、浅色、深色或 Liquid Glass。 |
| 更新 | 每 6 小时自动检查并安装，或点击**立即检查**。 |

更新从官方发布版下载，在不弹出安装程序窗口的情况下安装，SnapMark 会自动重新打开；你的设置和历史记录都会保留。如果你正在编辑，更新会等你完成后再安装。

## 隐私

- 截图和项目**绝不会离开你的电脑**。
- 没有遥测。唯一的网络访问是检查更新。

## 故障排除

**按 Print Screen 没反应 / 热键未生效。** Windows 11 可能会把该键分配给自带的截图工具。在 SnapMark 设置中点击**打开 Windows 键盘设置**，然后关闭让 Print Screen 键打开该工具的选项（选项的名称和位置因 Windows 版本而异）。或者选择其他热键。

**找不到通知区域图标。** 点击任务栏上的 ^ 箭头，把 SnapMark 图标拖出来，使其始终可见。

**数据位置。** 设置：`%APPDATA%\app.snapmark.desktop\settings.json`。历史记录：`%LOCALAPPDATA%\app.snapmark.desktop\history`。
