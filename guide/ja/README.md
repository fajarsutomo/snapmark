# SnapMark ユーザーガイド

SnapMark は Windows の画面をキャプチャし、**あとから編集できる**注釈を付けられるアプリです。四角、矢印、テキスト、マスクなどは画像に描き込まれたピクセルではなく、独立したオブジェクトです。元の画像が書き換えられることはありません。

## インストール

インストーラー `SnapMark_x.y.z_x64-setup.exe` を実行します。現在のユーザーだけにインストールされ、管理者権限は不要です。インストール後、SnapMark は**通知領域**（時計の近くのアイコン領域。タスクトレイとも呼ばれます） で動作します。アイコンが見えない場合は ^ をクリックして隠れたアイコンを表示してください。

通知領域のアイコンを右クリックするとメニューが開きます: **キャプチャ**、**履歴**、**プロジェクトを開く…**、**設定**、**終了**。

## 画面をキャプチャする

1. **Print Screen** を押します（通知領域のアイコンをクリック、または **キャプチャ** を選んでも可）。画面が一瞬止まります。モニターが複数ある場合はすべてキャプチャされます。
2. **ドラッグ**して範囲を選びます。範囲は注釈を付けたあとでもいつでも変更できます。**枠線**をドラッグして移動、角や辺の**ハンドル**をドラッグしてサイズ変更、外側の暗い部分をドラッグして選び直せます。矢印キーで範囲を動かし、**Ctrl + 矢印**でサイズを変更します。**Shift** を押すと 10 ピクセル単位になります。
3. ツールバーで注釈を追加します。
4. **Enter** でクリップボードにコピー、**Ctrl+S** で保存します。**Esc** でキャンセルします。

最初の Esc でオブジェクトの選択を解除し、次の Esc で SnapMark を閉じます。

## 注釈ツール

| ツール | キー | 補足 |
|---|---|---|
| 選択と編集 | `V` | オブジェクトをクリックして選択。**Shift+クリック**で選択に追加/除外。ドラッグで移動、ハンドルでサイズ変更。 |
| 四角形 | `R` | **Shift** = 正方形。塗りつぶし可。 |
| 楕円 | `E` | **Shift** = 円。 |
| 線 | `L` | **Shift** = 45° 刻み。スタイル: 実線、二重線、破線。 |
| 矢印 | `A` | **Shift** = 45°。片側または両側に矢じり。 |
| フリーハンド | `P` | 自由に描画。 |
| 蛍光ペン | `H` | 半透明のマーカー。 |
| マスク | `S` | モザイク、ぼかし、または**黒塗り**（最も安全）。四角形またはブラシ。 |
| ステップ番号 | `N` | クリックするたびに 1, 2, 3… と順に配置。 |
| テキスト | `T` | 背景を選べます。**Ctrl+Enter** または **Esc** で確定。 |

色、線の太さ、フォントサイズ、太字はツールバーで設定でき、選択中のオブジェクトに反映されます。

## キーボードショートカット

| キー | 動作 |
|---|---|
| `Enter` / `Ctrl+C` | 結果をクリップボードにコピー |
| `Ctrl+S` | 保存フォルダーに PNG を保存 |
| `Ctrl+Shift+S` | 名前を付けて保存… |
| `Ctrl+Alt+S` | `.snapmark` プロジェクトを保存 |
| `Ctrl+Z` / `Ctrl+Y`（または `Ctrl+Shift+Z`） | 元に戻す / やり直す |
| `Ctrl+D` | 選択中のオブジェクトを複製 |
| `Ctrl+A` | すべてのオブジェクトを選択 |
| `Ctrl+]` / `Ctrl+[` | 最前面へ / 最背面へ |
| `Delete` / `Backspace` | 選択中のオブジェクトを削除 |
| 矢印（`Shift` = 10 px） | 選択中のオブジェクトを移動。未選択なら範囲を移動（`Ctrl` 併用でサイズ変更） |
| `Esc` | 選択解除、もう一度で閉じる |

## コピーと保存

結果は常に**選択した範囲だけ**で、画面の**元の解像度**のまま、見たとおりに出力されます。

- **コピー** (Enter): クリップボードに入り、そのまま貼り付けられます。
- **保存** (Ctrl+S): 保存フォルダーに `snapmark_20261125_143005.png`（日付_時刻） の名前で直接保存します。同名のファイルは上書きされません（`_2`、`_3`… が付きます）。既定のフォルダーは `ピクチャ\SnapMark` です。
- **名前を付けて保存** (Ctrl+Shift+S): 名前とフォルダーを自分で選びます。

コピーまたは保存に成功すると、SnapMark は自動的に閉じます。

## プロジェクトと履歴

**`.snapmark` プロジェクト**は元の画像とすべての注釈をオブジェクトとして保存するので、あとで開いて再編集できます。**Ctrl+Alt+S** で保存し、ファイルをダブルクリックするか、通知領域 → **プロジェクトを開く…** で開きます。

> **マスクにご注意ください。** プロジェクトファイルには*元の画像*が含まれるため、マスクした部分もそのファイルを開いた人には見えてしまいます。共有するときは、マスクした結果だけを含む **コピー** または **PNG を保存** を使ってください。マスクを含むプロジェクトを保存する前に、SnapMark が警告します。

**履歴**: コピー/保存のたびに、編集可能なプロジェクトとして自動記録されます（既定で直近 50 件、このコンピューター内のみ）。通知領域 → **履歴** から開き、項目をクリックすると再編集できます。

## 設定

通知領域 → **設定**。

| 項目 | 説明 |
|---|---|
| キャプチャのホットキー | 既定は `Print Screen`。**変更…** をクリックして新しい組み合わせを押します（入力の邪魔にならないよう Ctrl/Alt/Win を併用してください）。 |
| 保存フォルダー | Ctrl+S の保存先。 |
| 言語 | Bahasa Indonesia、English、Español、Deutsch、日本語、简体中文、Français、Italiano、Português (Brasil)、한국어、Русский、العربية、Nederlands、または Windows に合わせる。 |
| 履歴 | 保持する件数（0 = オフ、最大 500）。 |
| Windows と同時に起動 | サインイン後すぐ SnapMark が使えます。 |
| ヒントの色 | 範囲選択中に表示される説明文の色。 |
| テーマ | Windows に合わせる、ライト、ダーク、Liquid Glass。 |
| アップデート | 6 時間ごとに自動で確認・インストール、または **今すぐ確認**。 |

アップデートは公式リリースからダウンロードされ、インストーラーのウィンドウなしでインストールされ、SnapMark は自動で再起動します。設定と履歴は保持されます。編集中の場合は、終わるまでインストールを待ちます。

## プライバシー

- スクリーンショットとプロジェクトは**このコンピューターの外に出ません**。
- テレメトリはありません。ネットワークアクセスはアップデートの確認だけです。

## トラブルシューティング

**Print Screen を押しても何も起きない / ホットキーが無効。** Windows 11 はこのキーを独自の画面キャプチャツールに割り当てることがあります。SnapMark の設定で **Windows のキーボード設定を開く** をクリックし、Print Screen キーでそのツールを開くオプションをオフにしてください（オプションの名前と場所は Windows のバージョンによって異なります）。または別のホットキーを選びます。

**通知領域のアイコンが見つからない。** タスクバーの ^ をクリックし、SnapMark のアイコンを外へドラッグすると常に表示されます。

**データの場所。** 設定: `%APPDATA%\app.snapmark.desktop\settings.json`。履歴: `%LOCALAPPDATA%\app.snapmark.desktop\history`。
