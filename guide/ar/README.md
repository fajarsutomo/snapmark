# دليل استخدام SnapMark

يلتقط SnapMark شاشة Windows ويتيح لك إضافة تعليقات توضيحية **تبقى قابلة للتحرير**: المستطيلات والأسهم والنصوص وأدوات الإخفاء وغيرها كلها كائنات مستقلة، وليست بكسلات مرسومة على الصورة. ولا تُعدَّل الصورة الأصلية أبدًا.

## التثبيت

شغّل المثبّت `SnapMark_x.y.z_x64-setup.exe`. يُثبَّت لحسابك فقط (لا يحتاج إلى صلاحيات المسؤول). بعد ذلك يعمل SnapMark في **منطقة الإعلام** (منطقة الأيقونات قرب الساعة، وتُسمّى أيضًا علبة النظام). إن لم تظهر الأيقونة فانقر السهم ^ لإظهار الأيقونات المخفية.

انقر بزر الفأرة الأيمن على الأيقونة لفتح القائمة: **التقاط**، **السجل**، **فتح مشروع…**، **الإعدادات**، **خروج**.

## التقاط الشاشة

1. اضغط **Print Screen** (أو انقر أيقونة منطقة الإعلام، أو اختر **التقاط**). تتجمد الشاشة لحظة؛ وإذا كان لديك عدة شاشات فتُلتقط كلها.
2. **اسحب** لتحديد منطقة. يمكنك تغييرها في أي وقت، حتى بعد إضافة التعليقات: اسحب **حدودها** لنقلها، أو **مقبضًا** في زاوية أو جانب لتغيير حجمها، أو اسحب في المنطقة الداكنة خارجها لاختيار منطقة جديدة. مفاتيح الأسهم تحرّك المنطقة؛ و**Ctrl + سهم** يغيّر حجمها؛ و**Shift** يجعل الخطوة 10 بكسلات.
3. استخدم شريط الأدوات لإضافة التعليقات.
4. اضغط **Enter** للنسخ إلى الحافظة، أو **Ctrl+S** للحفظ. و**Esc** للإلغاء.

أول ضغطة على Esc تُلغي تحديد الكائنات، والثانية تُغلق SnapMark.

## أدوات التعليق

| الأداة | المفتاح | ملاحظات |
|---|---|---|
| تحديد وتحرير | `V` | انقر كائنًا لتحديده؛ **Shift+نقر** يضيف إلى التحديد أو يزيل منه. اسحب للنقل، واسحب مقبضًا لتغيير الحجم. |
| مستطيل | `R` | **Shift** = مربع. يمكن تعبئته. |
| إهليلج | `E` | **Shift** = دائرة. |
| خط | `L` | **Shift** = تثبيت الزاوية على مضاعفات 45°. الأنماط: متصل، مزدوج، متقطع. |
| سهم | `A` | **Shift** = 45°. رأس سهم في طرف واحد أو في الطرفين. |
| قلم حر | `P` | رسم حر. |
| قلم تمييز | `H` | علامة شبه شفافة. |
| إخفاء | `S` | فسيفساء أو تمويه أو **كتلة سوداء** (الأكثر أمانًا). بشكل مستطيل أو بالفرشاة. |
| رقم الخطوة | `N` | كل نقرة تضع 1 ثم 2 ثم 3… بالترتيب. |
| نص | `T` | يمكن اختيار الخلفية. **Ctrl+Enter** أو **Esc** للإنهاء. |

يُضبط اللون وسماكة الخط وحجم الخط والتغميق من شريط الأدوات، وتسري التغييرات على الكائنات المحددة.

## اختصارات لوحة المفاتيح

| المفتاح | الإجراء |
|---|---|
| `Enter` / `Ctrl+C` | نسخ النتيجة إلى الحافظة |
| `Ctrl+S` | حفظ PNG في مجلد الحفظ |
| `Ctrl+Shift+S` | حفظ باسم… |
| `Ctrl+Alt+S` | حفظ مشروع `.snapmark` |
| `Ctrl+Z` / `Ctrl+Y` (أو `Ctrl+Shift+Z`) | تراجع / إعادة |
| `Ctrl+D` | تكرار الكائنات المحددة |
| `Ctrl+A` | تحديد كل الكائنات |
| `Ctrl+]` / `Ctrl+[` | إلى الأمام / إلى الخلف |
| `Delete` / `Backspace` | حذف الكائنات المحددة |
| الأسهم (`Shift` = 10 px) | تحريك الكائنات المحددة؛ وإن لم يكن هناك تحديد فتحريك المنطقة (مع `Ctrl`: تغيير حجمها) |
| `Esc` | إلغاء التحديد، ثم الإغلاق |

## النسخ والحفظ

النتيجة دائمًا **المنطقة المحددة فقط** بـ**دقة الشاشة الأصلية**، تمامًا كما تراها.

- **نسخ** (Enter): تذهب إلى الحافظة جاهزة للصق.
- **حفظ** (Ctrl+S): مباشرة في مجلد الحفظ باسم مثل `snapmark_20261125_143005.png` (التاريخ_الوقت). لا تُستبدل الملفات الموجودة أبدًا (يُضاف اللاحق `_2` و`_3` و…). المجلد الافتراضي: `الصور\SnapMark`.
- **حفظ باسم** (Ctrl+Shift+S): تختار الاسم والمجلد بنفسك.

بعد نجاح النسخ أو الحفظ يُغلق SnapMark تلقائيًا.

## المشاريع والسجل

**مشروع `.snapmark`** يحفظ الصورة الأصلية وكل تعليق ككائن، فيمكنك فتحه وتحريره لاحقًا. احفظ بـ**Ctrl+Alt+S**؛ وافتحه بالنقر المزدوج على الملف، أو من منطقة الإعلام ← **فتح مشروع…**.

> **احذر عند الإخفاء.** لأن ملف المشروع يحتفظ بالصورة *الأصلية*، يستطيع أي شخص يفتح الملف رؤية ما أخفيته. للمشاركة استخدم **نسخ** أو **حفظ PNG** فهما يحتويان على النتيجة المخفية فقط. ينبّهك SnapMark قبل حفظ مشروع يحتوي على إخفاء.

**السجل**: يُسجَّل كل نسخ/حفظ تلقائيًا كمشروع قابل للتحرير (آخر 50 افتراضيًا، على هذا الحاسوب فقط). افتحه من منطقة الإعلام ← **السجل** وانقر عنصرًا لتحريره من جديد.

## الإعدادات

منطقة الإعلام ← **الإعدادات**.

| الإعداد | الوصف |
|---|---|
| اختصار التقاط الشاشة | الافتراضي `Print Screen`. انقر **تغيير…** ثم اضغط التركيبة الجديدة (استخدم Ctrl/Alt/Win كي لا تزعجك أثناء الكتابة). |
| مجلد الحفظ | وجهة Ctrl+S. |
| اللغة | Bahasa Indonesia وEnglish وEspañol وDeutsch و日本語 و简体中文 وFrançais وItaliano وPortuguês (Brasil) و한국어 وРусский والعربية وNederlands، أو مثل Windows. |
| السجل | عدد العناصر المحفوظة (0 = متوقف، 500 كحد أقصى). |
| التشغيل مع Windows | يكون SnapMark جاهزًا فور تسجيل الدخول. |
| لون التلميح | لون نص التعليمات أثناء تحديد المنطقة. |
| السمة | مثل Windows أو فاتحة أو داكنة أو Liquid Glass. |
| التحديثات | فحص وتثبيت تلقائي كل 6 ساعات، أو زر **افحص الآن**. |

تُنزَّل التحديثات من الإصدار الرسمي وتُثبَّت دون نافذة مثبِّت، ويُعاد فتح SnapMark تلقائيًا؛ وتبقى إعداداتك وسجلك. وإذا كنت تحرّر فينتظر التحديث حتى تنتهي.

## الخصوصية

- اللقطات والمشاريع **لا تغادر حاسوبك أبدًا**.
- لا توجد قياسات عن بُعد. الوصول الوحيد إلى الشبكة هو فحص التحديثات.

## استكشاف الأخطاء وإصلاحها

**Print Screen لا يفعل شيئًا / الاختصار غير نشط.** قد يخصّص Windows 11 هذا المفتاح لأداة التقاط الشاشة الخاصة به. في إعدادات SnapMark انقر **فتح إعدادات لوحة المفاتيح في Windows** ثم أوقف الخيار الذي يجعل مفتاح Print Screen يفتح تلك الأداة (يختلف اسم الخيار ومكانه بحسب إصدار Windows). أو اختر اختصارًا آخر.

**أيقونة منطقة الإعلام غير ظاهرة.** انقر السهم ^ في شريط المهام، واسحب أيقونة SnapMark إلى الخارج لتبقى ظاهرة دائمًا.

**مكان البيانات.** الإعدادات: `%APPDATA%\app.snapmark.desktop\settings.json`. السجل: `%LOCALAPPDATA%\app.snapmark.desktop\history`.
